# Asset Scraper Studio

Ein modernes Werkzeug zur Suche, Analyse und Archivierung von Assets aus Browsergames, Webseiten und digitalen Projekten.

Entwickelt von **CodeMajorX**.

---

## Funktionen

### Asset-Suche

* Durchsuchen von Webseiten nach Assets
* Rekursive Suche mit einstellbarer Suchtiefe
* Optional nur gleiche Domain / gleicher Host
* Filterung nach Dateitypen

### Unterstützte Dateitypen

* SWF
* AS
* XML
* JSON
* JS
* CSS
* PNG
* JPG / JPEG
* GIF
* SVG
* WEBP
* MP3
* OGG
* WAV
* ZIP
* RAR
* 7Z
* BIN
* DAT
* CFG
* INI

### Download-System

* Mehrfach-Downloads
* Erneuter Download fehlerhafter Dateien
* Nur neue Dateien herunterladen
* Vorhandene Dateien überspringen
* ZIP-Export

### Validierung & Qualitätskontrolle

* Erkennung von 404-Fehlern
* Erkennung von 403-Fehlern
* Erkennung von 0-Byte-Dateien
* SWF-Header-Prüfung
* Markierung ungültiger Dateien

### Datenbank & Projektverwaltung

* Mehrere Projekte verwalten
* Lokale Asset-Datenbank
* Favoriten-System
* Tag-System
* CSV-Export
* TXT-Export
* Such- und Filterfunktionen

### Benutzeroberfläche

* Modernes Dark-Theme
* Mehrsprachige Oberfläche
* Automatische Skalierung
* Projektprofile
* Explorer-Ansicht
* Statistiken und Übersichten

---

## Einsatzgebiete

Asset Scraper Studio eignet sich unter anderem für:

* Archivierung alter Browsergames
* Analyse von Webseiten
* Digitale Langzeitarchivierung
* Forschungs- und Dokumentationsprojekte
* Wiederherstellung historischer Web-Inhalte
* Asset-Recherche und Projektanalyse
